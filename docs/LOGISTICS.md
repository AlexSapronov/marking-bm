# Инструкция логиста

**Сервис:** marking-bm. **Роль:** «Логист». **Редакция:** 28.10.2026.

## 1. Вход и границы рабочего места

Администратор создаёт учётную запись и передаёт одноразовый код установки первого пароля. На странице **«Первый вход / сброс пароля»** введите username, код, новый пароль длиной не менее восьми символов и его повторение. В дальнейшем входите по собственному паролю.

После входа откроется **«Реестр АТК»** для всех сотрудников ОБМ. Логист **не может** заказывать КМ, создавать или исправлять накладные, отправлять отчёты, инициировать трансформации АТК либо менять настройки.

## 2. Найти комплект

В реестре видны АТК, поставщики, номера накладных, сотрудники, ТН ВЭД, количество КМ и единиц товара, состояние АТК и доступные версии файлов.

Используйте поиск по номеру накладной или АТК, фильтры поставщика, статуса, ТН ВЭД, даты и флаг **«Архивные АТК»**. Изменения поиска применяются через **«Применить фильтры»**, выбор некоторых фильтров применяет их автоматически. Доступны сортировка внутри групп поставщиков и страницы **25 / 50 / 100 АТК**.

Важно различать:
- **«АТК формируется»**: ещё нет подтверждённо сформированного АТК.
- **«АТК сформирован»**: внешний результат АТК готов; наличие обоих итоговых файлов проверяется отдельно.
- **«Готовы к скачиванию»**: сервер нашёл достаточные сохранённые файлы для скачивания; статус не означает физическое получение груза.
- **«Комплект сформирован»** в накладной ОБМ: АТК/RESULT подготовлены, но **логист ещё не обязательно брал документ в работу**.

Приложение не фиксирует физическое формирование груза, погрузку, отгрузку, маршрут, прохождение таможни или складскую приёмку. Эти события нельзя выводить из названия стадии.

## 3. Скачивание АТК и RESULT

Для одного АТК используйте ссылки **«АТК · v…»** и **«RESULT · v…»**. Для нескольких:
1. Отметьте только готовые АТК; у остальных видна причина недоступности.
2. При переключении страниц выбранные АТК сохраняются. **«Выбрать все» действует только на текущей странице**.
3. Перед скачиванием проверьте отображённое количество выбранных АТК, уникальных комплектов и накладных. При изменении фильтров система предупреждает о сбросе выбора.
4. Нажмите **«Скачать ZIP»**. Не более **200 АТК за скачивание**. Общие АТК/RESULT одной группы поставщика попадают в ZIP один раз.

Нажмите код АТК для просмотра его состава и файлов. **Актуальные** файлы отделены от **устаревших**. Прежние версии нужны для аудита, их нельзя без проверки использовать для текущего оформления.

Само скачивание не подтверждает приёмку и не меняет статус накладной.

## 4. Ввод в оборот и завершение накладной

После выпуска товаров таможней нажмите **«Ввести в оборот»** в реестре, чтобы открыть карточку АТК. Открытие карточки ещё не отправляет документ в ГИС МТ.

В карточке нажмите **«Ввести в оборот»**. Откроется форма **«Ввод в оборот · Импорт с ФТС»**:

1. Проверьте список накладных и АТК. Общий АТК вводится целиком: все связанные накладные и АТК комплекта включаются в один документ по одной ДТ. Если они выпущены по разным ДТ, отправлять этот комплект нельзя: сначала требуется согласовать его разделение.
2. Укажите регистрационный номер ДТ `XXXXXXXX/ДДММГГ/XXXXXXX` и дату регистрации. Дата должна совпадать с номером, быть не ранее 01.01.2000 и не позднее текущей даты.
3. Укажите трёхзначный код ОКСМ страны производства для всех строк или отдельно для каждой строки (например, Китай — 156, Тайвань — 158). В таблице виден полный ТН ВЭД каждой строки.
4. После положительного выпуска таможней нажмите **«Подписать и ввести в оборот»**. Документ передаётся существующему Windows-подписанту с УКЭП настроенной организации, затем в ГИС МТ как `LP_FTS_INTRODUCE`.

Каждый КМ передаётся внутри своего АТК с явно заполненными `tn_ved` (полные 10 цифр из строки накладной) и `production_country_code`. Перед отправкой проверяются ТН ВЭД в накладной, КМ, АТК и ГИС МТ, собственник, статус и фактический родитель каждого КМ. Изменение состава АТК после постановки ввода в очередь запрещено.

Накладные перемещаются в архив **после успешной обработки документа и подтверждения статуса `INTRODUCED` всех КМ в ГИС МТ**. Ожидание ФТС, отрицательное решение, частичный результат и потеря ответа не завершают накладные. Повторное нажатие не создаёт дубль. При неизвестном результате администратор сверяет документ в ЛК ЧЗ, привязывает внешний ID и запрашивает проверку статуса; автоматическая повторная отправка запрещена. Ошибки доступны в карточке и колонке следующего действия. История, внешний ID и квитанция сохраняются, АТК и RESULT доступны в архивном реестре.

Старый endpoint локального завершения `/complete` возвращает отказ: он больше не может закрывать накладную вместо ввода в оборот. Старые архивные документы не отправляются автоматически.

## 5. Если комплект не готов или есть ошибка

Если АТК формируется, файл отсутствует либо операция требует проверки, **не запускайте новый заказ КМ и не изменяйте внешние документы вручную**. Обновите реестр; при сохраняющейся проблеме передайте администратору код АТК, номер накладной, поставщика и текст ошибки.

При появлении неожиданного старого файла проверяйте версию. При несоответствии состава, количества, ТН ВЭД или поставщика остановите оформление и сообщите ОБМ/администратору. Не используйте устаревшую версию только потому, что она скачивается.

## 6. Контроль перед выходом

Проверьте нужного поставщика и номера накладных, наличие именно актуальных АТК/RESULT, количества штук и КМ. Сохраняйте комплект согласно внутреннему регламенту и только после требуемой проверки закрывайте накладную в системе.

**Важная оговорка:** в текущей версии действует шестимесячный механизм автоархивации некоторых накладных. Проверка его соответствия процессу отдельная задача [#41](https://github.com/AlexSapronov/marking-bm/issues/41). Поэтому один только статус архива не является доказательством действия конкретного логиста.
