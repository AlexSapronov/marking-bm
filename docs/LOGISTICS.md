# Рабочее место логиста

Администратор создаёт ваш username с ролью «Логист». Входите под ним на общей странице приложения, как обычный сотрудник. После входа автоматически откроется «Реестр АТК».

В реестре доступны АТК всех бренд-менеджеров: поставщик, номера накладных, сотрудники, полный ТН ВЭД, количество штук и КМ, статус обработки и дата создания. Формирующиеся АТК тоже видны, но не выдаются за готовые к скачиванию.

## Найти нужные АТК

- Введите код АТК или номер накладной в поиск.
- Выберите поставщика, статус или ТН ВЭД. Можно указать часть кода ТН ВЭД.
- При необходимости задайте период создания.
- Нажмите «Применить фильтры». При выборе поставщика или статуса список обновляется сразу.
- Для старых документов включите «Архивные АТК». Кнопка «Сбросить» возвращает основной список.

## Скачать файлы

В строке готового АТК доступны кнопки «АТК» и «RESULT» с номером версии. Они скачивают актуальные итоговые Excel.

Чтобы получить несколько комплектов, отметьте готовые АТК и нажмите «Скачать выбранные · ZIP». Один комплект АТК + RESULT может содержать несколько АТК одного поставщика: общие файлы включаются в ZIP только один раз. Сами файлы сохраняют согласованные имена с поставщиком и номерами накладных.

Нажмите на код АТК, чтобы посмотреть его состав, количества, текущие файлы и предыдущие версии. Архивные файлы также доступны.

Если комплект ещё формируется, кнопки скачивания отсутствуют. Обновите реестр позже. Ошибку обработки видит администратор; повторно заказывать КМ или менять документы логисту не нужно.

## Права

Роль логиста предназначена для просмотра АТК и скачивания АТК/RESULT. Она не даёт доступа к исходным Excel накладных и PDF этикеток, созданию/редактированию накладных, заказу КМ, отчётам, трансформациям или настройкам системы.

Роль назначается в админке, а не выбирается при входе. При изменении роли активные обычные сессии пользователя завершаются: нужно войти заново. Вход под username по принятому процессу остаётся без пароля.

Кнопка темы в верхней панели переключает светлую и тёмную темы. Выбор сохраняется в браузере; палитра и элементы управления совпадают с gis-trueapi и km-split.
