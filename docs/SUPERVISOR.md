# Инструкция руководителя

**Сервис:** marking-bm. **Роль:** «Руководитель».

## 1. Доступные разделы

После входа доступны два раздела:

- **«Накладные» и «Архив»**: просмотр накладных всех сотрудников, состава товаров, владельца, статусов, истории обработки и истории документа.
- **«Реестр АТК»**: просмотр общего реестра, состава АТК и статусов, скачивание отдельных актуальных файлов АТК/RESULT или комплектов ZIP.

## 2. Только чтение

Руководитель не выполняет рабочие операции ОБМ или логиста. Ему недоступны создание и редактирование накладных, загрузка Excel, заказ КМ, формирование и скачивание этикеток, подтверждение передачи, отчёты о нанесении, перенос строк и КМ, остановка и дополнение накладных, трансформации и закрытие накладных в логистике.

В разделе «Накладные» руководитель видит документы всех владельцев. Файлы АТК и RESULT нужно скачивать через «Реестр АТК». Прямое обращение к рабочим API ОБМ не предоставляет полномочий на изменение данных. Сервер отдельно проверяет права, поэтому скрытие кнопок в интерфейсе не является единственным ограничением.

В «Реестре АТК» доступны просмотр, прямое скачивание актуальных АТК/RESULT и скачивание ZIP для выбранных готовых комплектов. Руководитель не может закрывать накладные в системе. Управление пользователями, сброс чужих паролей, конфигурация, административные согласования, восстановление операций и другие функции администратора остаются закрытыми.

## 3. Вход и пароль

Администратор создаёт учётную запись с ролью «Руководитель» и передаёт одноразовый код первого входа. Установите собственный пароль длиной не менее восьми символов, введя его дважды. В дальнейшем входите по username и паролю. Для смены собственного пароля используйте **«Сменить пароль»**; при утрате доступа запросите у администратора сброс.
