# Состав реализации и проверка

Редакция: 16.11.2026. [README](../README.md).

Приложение содержит FastAPI API, HTML/JavaScript интерфейс, SQLite WAL, долговечную очередь, реальные клиенты СУЗ/True API и отдельный Windows-подписант. Деморежима в runtime нет. Внешняя отправка управляется `BM_ALLOW_EXTERNAL_WRITES`.

## Реализованные сценарии

- Импорт Excel с автопоиском и ручным сопоставлением столбцов, контроль GTIN/ТН ВЭД, подтверждение изменений.
- Общий пул EMITTED, резервирование и заказ только дефицита; частичное получение и восстановление конкретного блока.
- Версии PDF/ZIP 58×40 мм, передача этикеток, отдельные отчёты нанесения, группы АТК и RESULT.
- Роли ОБМ, логиста, руководителя и администратора; индивидуальные пароли, одноразовая установка, CSRF, ACL.
- Перенос целых строк до нанесения, дополнения, согласуемые трансформации, остановка и возврат.
- Административное исправление GTIN, расформирование и пересборка груза, разрешение расхождения ТН ВЭД для АТК до отправки.
- Ввод в оборот «Импорт с ФТС», проверка INTRODUCED, версионная передача/отзыв приёмок в gis-trueapi.
- Неизменяемые файлы и аудит, резервное копирование с проверкой целостности и контрольных сумм.

## Как проверить текущий коммит

Команды и условия: [ACCEPTANCE.md](ACCEPTANCE.md), [SERVICE_MANUAL.md](SERVICE_MANUAL.md).
`tests/` содержит API, worker, права, ошибки интеграций, DataMatrix/PDF и браузерные сценарии. Точный результат и число тестов относятся к конкретному запуску CI, а не являются постоянным свойством продукта.

В автотестах внешние HTTP-ответы имитируются. Они не подтверждают права конкретной организации, работу физического токена, печать на производственном принтере или обработку документа продуктивным контуром. Эти условия проверяются на целевом рабочем месте без дублирования платных операций.

Скриншоты и примеры рабочих файлов с товарными идентификаторами не включаются в публичное руководство. Правила публикации: [PRIVACY.md](PRIVACY.md).
