# Результат реализации

Дата: 24.10.2026. Последующее указание владельца: никаких деморежимов. Оно применено ко всему runtime: нет генератора фиктивных КМ/АТК и переключателя demo/mock. Подмены внешних сервисов существуют только в автотестах.

Поставлены backend/frontend, транзакционная БД, реальный клиент СУЗ / True API, централизованный Windows-подписант, deploy/backup/restore, инструкции и официальная карта интеграций.

## Проверено в среде разработки

- 27 pytest-проверок прошли: импорт и глобальные соответствия, confirmation/revision, смена разбивки, переиспользование пула, гонки и повторные клики, неполный комплект, отдельные отчёты и независимые группы, группировка по полному ТН ВЭД, два Excel, ошибки/таймауты/рестарт, восстановление конкретного блока, согласования, дополнения, права/CSRF/signing leases, шестимесячный архив и восстановление backup.
- GS1 DataMatrix обоих криптоформатов реально декодирован ZXing из PDF; размер страницы 58×40 мм, serial 20, GS, AI 30, криптохвост и специальные печатные последовательности сохранены.
- Chromium: административный вход, создание пользователя и накладной, редактирование и сохранение строк, перезагрузка карточки, фильтр списка, мобильная ширина, отсутствие ошибок JS. Скриншоты в `docs/screenshots/`.
- Python: Ruff F-check; JavaScript: синтаксическая проверка Node. Runtime-зависимости зафиксированы в `requirements-lock.txt`.
- В тестах HTTP перехватывается `httpx.MockTransport`; внешние заказы не выполняются. Браузер запускает обычное приложение с отключённой внешней отправкой, без подмены UI-данных.

## Требует инфраструктуры владельца

- Продуктивные credentials, права организации и фактическая доступность API.
- Локальный PoC `-Diagnose` на Windows с реальным Рутокеном: COM, лицензия, сертификат user-store, PIN/касание, повторная/фоновая подпись. В Linux это проверить невозможно. Браузерный запасной подписант не заявлен реализованным: при недоступном COM требуется отдельная проверенная реализация на официальном плагине.
- Согласованная первая реальная платная операция, квитанции конкретного контура, физическая печать и сканирование этикетки.
- Развёртывание на конкретном VPS, корпоративный HTTPS, backup на отдельный носитель.

Без этих проверок нельзя утверждать, что полностью автоматическая продуктивная цепочка подтверждена. Приложение не подменяет ожидание подписи/квитанции успешным результатом. Платные заказы, отчёты и АТК разработчик не отправлял.
