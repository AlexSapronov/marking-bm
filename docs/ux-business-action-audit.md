# Действия интерфейса и бизнес-результаты

Редакция: 16.11.2026. Словарь текущих действий; он не подтверждает физическое движение груза.

| Действие | Результат | Что проверить |
|---|---|---|
| Проверить и сохранить состав | Локальная версия строк накладной | PN, GTIN, фасовка, количество, ТН ВЭД и предупреждения |
| Заказать КМ | Подбор EMITTED и очередь эмиссии дефицита | Состав и отсутствие уже отправленного заказа |
| Скачать ZIP/PDF | Сохранённая версия этикеток | Актуальность версии; скачивание не означает нанесение |
| Подтвердить передачу этикеток | Отметка передачи конкретной версии | Фактическая передача по согласованному каналу |
| Подтвердить нанесение и создать отчёт | Очередь подписи и отправки отчёта | Фактическое нанесение и дата производства |
| Сформировать АТК | Очередь внешней операции после принятых отчётов | Полный состав, ТН ВЭД, успешная квитанция |
| Скачать АТК/RESULT/ZIP | Чтение готовых версий файлов | Не подтверждает перевозку, таможенный выпуск или ввод |
| Ввести в оборот | LP_FTS_INTRODUCE для полного связанного состава | Выпуск, ДТ/дата, страны, статусы всех КМ; дождаться INTRODUCED |
| Остановить и архивировать | Удержание дальнейшей обработки и сохранение истории | Не отзывает уже отправленный запрос и не возвращает оплату |
| Вернуть из архива | Административное возобновление с причиной | Внешние результаты, зависимые операции и удержания |
| Повторить предпроверку | Новая проверка до отправки | Не равнозначна отправке или принятию ЧЗ |
| Указать внешний ID | Привязка найденного результата | Сверить ЛК; повторная отправка не выполняется |
| Исправить GTIN | Контролируемый план корректировки и новая версия этикеток | Нельзя молча менять уже принятый отчёт |
| Расформировать АТК и исправить груз | Отзыв приёмок, подпись расформирования, перенос целых строк | Вся группа поставщика и зависимые документы |
| Принудительный АТК | Разрешение расхождения ТН ВЭД для точного payload | Только администратор, preflight_blocked без внешнего ID, обязательная причина |

`done` накладной означает «Комплект сформирован». `done` внешней операции означает подтверждённый результат этой операции. Архив может иметь разные основания: ввод в оборот, остановка или календарное правило. Основание проверяется по истории; архив сам не доказывает доставку.

Руководитель работает только на чтение. Отсутствие кнопки не заменяет серверную проверку прав. Заблокированное действие должно показывать причину; запрос вручную не должен обходить ограничения.
