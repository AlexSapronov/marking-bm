# Функциональные требования marking-bm

Редакция: 16.11.2026. Документ описывает текущие границы продукта; исходная постановка и обсуждения не являются эксплуатационной инструкцией.

## Назначение

Подготовка маркировки импортной радиоэлектроники: накладная → состав → КМ → этикетки → подтверждение нанесения → отчёт → АТК/RESULT → ввод в оборот «Импорт с ФТС». Складская приёмка передаётся в отдельный gis-trueapi. Деление КМ через DIVISIONMARK относится к km-split.

## Обязательные свойства

| Область | Требование |
|---|---|
| Доступ | Индивидуальные пароли сотрудников, роли ОБМ/логист/руководитель, отдельные администратор и подписант; серверная ACL |
| Импорт | PN, GTIN, штук в этикетке, число этикеток, полный ТН ВЭД; контроль целых количеств и конфликтов, предпросмотр и подтверждение |
| КМ | Полная кодовая последовательность с криптохвостом, GS и регистром; общий пул только пригодных EMITTED; транзакционный резерв |
| Эмиссия | IMPORT, оплата по эмиссии, только дефицит; неизвестный результат не повторяется автоматически |
| Файлы | Версии PDF 58×40, ZIP и Excel сохраняются; перепечатка не вызывает новую эмиссию |
| Нанесение | Явное подтверждение, отчёт по накладной, проверка внешнего результата |
| АТК | После принятых отчётов группы; полный ТН ВЭД, реальный код из ЧЗ, версии состава и итоговых файлов |
| Исправления | Контролируемый перенос строк, корректировка GTIN, трансформации и расформирование; история остаётся неизменной |
| Логистика | Реестр АТК/RESULT, ввод по ДТ и странам производства; архив после подтверждённого INTRODUCED |
| Приёмки | Отдельный черновик на накладную, идемпотентность, версии состава, отзыв при исправлении груза |
| Эксплуатация | Один backend worker, долговечная очередь, разбор unknown, резервирование и восстановление |

## Ограничения

Сервис не фиксирует физическую перевозку и не подменяет сканирование склада. Успешный локальный запрос, heartbeat и скачивание файла не равны успешной операции в ЧЗ. Исключение ТН ВЭД для АТК разрешается только администратором для точного payload до отправки; оно не отменяет прочие проверки.

Шестимесячное автоархивирование done без связанной операции ввода остаётся отдельным механизмом; причина архива проверяется по аудиту. Продуктивные права, сертификат и принтер проверяются при внедрении.
